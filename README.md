# Converter-Files
Easily convert files: PNG/JPEG to WEBP, and MP4 to WEBM.
(GIF and WEBP files are copied to the output as-is.)

When downloaded, follow these steps:

1. Put your files (PNG, JPG, JPEG, MP4, GIF, WEBP) into the `input` folder.
2. Run `exec.bat` (double-click it).
3. Choose an option to convert: Best Quality, Balanced, or Lower Quality.
4. If you don't have ffmpeg, the script downloads it only for this project —
   it doesn't install or change anything on your computer.
5. See the results in the `output` folder. Your original files stay in `input`.
